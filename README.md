# OutFox 🦊
> Intelligent Multi-Channel Outreach Engine for LinkedIn & Email Automation.

## Features
- **Automated LinkedIn Workflows:** Profile visits, personalized connection requests, and smart follow-up messaging.
- **Multi-Model AI Engine:** Real-time icebreaker personalization with automatic fallback (Groq, Gemini, OpenAI, Claude).
- **Google Sheets CRM Sync:** Live 2-way real-time spreadsheet synchronization.
- **Smart Safety Guardrails:** Human pacing delays (45–120s), working hours scheduling, and connection degree validation.
- **100% Free & Self-Hosted:** Direct local browser execution with complete privacy.

## Installation
1. Clone or download this repository.
2. Open Brave or Chrome and navigate to `brave://extensions` (or `chrome://extensions`).
3. Enable **Developer mode** (top right toggle).
4. Click **Load unpacked** and select the `extension/` directory.
